# Хароҷоти Ман (khacojoti-man)

Барномаи замонавии идораи хароҷот ва молияи шахсӣ (PWA) бо истифода аз React, Vite, TypeScript, Tailwind CSS ва Firebase (Auth, Firestore, Hosting).

## Хусусиятҳои асосӣ
- **Интерфейси тоҷикӣ**: Тамоми бахшҳо ва тугмаҳо пурра бо забони тоҷикӣ тарҳрезӣ шудаанд.
- **Ҳисоби маблағ**: Бо пули миллии Тоҷикистон (сомонӣ - TJS). Дар пойгоҳи додаҳо маблағҳо бо бутуни **дирам** нигоҳ дошта мешаванд (1 сомонӣ = 100 дирам).
- **Минтақаи вақт**: Тамоми санаҳо бо минтақаи расмии `Asia/Dushanbe` сабт ва намоиш дода мешаванд.
- **Саҳифаҳо**:
  - **Панели асосӣ (Dashboard)**: Маълумоти умумӣ, хароҷоти охирин, иловакунии фаврӣ ва ҳолати ҳамоҳангсозӣ.
  - **Таърих (History)**: Рӯйхати мукаммали хароҷот бо филтр, ҷустуҷӯ, таҳрир ва несткунӣ.
  - **Ҳисоботҳо (Reports)**: Диаграмма ва тақсимоти хароҷот аз рӯи категорияҳо ва моҳҳо.
  - **Буҷет (Budget)**: Танзими лимити моҳона ва назорати хароҷот бо огоҳиномаи пешгирикунанда.
  - **Категорияҳо (Categories)**: Идора ва иловакунии гурӯҳҳои хароҷот.
  - **Профил (Profile)**: Маълумоти корбар ва баромадан аз система.
- **Офлайн-реҷа (Offline PWA)**: Маълумот дар ҳолати набудани интернет дар ҳофизаи маҳаллӣ (IndexedDB) сабт шуда, пас аз пайвастшавӣ ба интернет бо ҳолати "Ҳамоҳанг шуд" ба Firestore интиқол меёбад.
- **Амният**: Қоидаҳои қатъии Firestore — ҳар корбар танҳо ба маълумоти худ (`users/{uid}/**`) дастрасӣ дорад.

## Ба кор андохтан (Local Development)
```bash
npm install
npm run dev
```

## Санҷишҳо ва сохтмон
```bash
npm run typecheck
npm test
npm run build
```
